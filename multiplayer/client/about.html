What This Is

Tidal Wave is an online multiplayer ocean card strategy game. The server is authoritative so players share one consistent state while joining, reconnecting, and restarting matches.

Why It Exists

This project was built to make two-player online games easier to run and more resilient during live sessions. It supports seat reclaim, room persistence, and reconnect-friendly gameplay.

Current Focus

The priority is stable multiplayer play, clean game flow, and accurate scoring behavior without changing game mechanics.
